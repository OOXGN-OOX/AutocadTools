# Сторонние компоненты

Этот файл содержит сведения о зависимостях Autocad Tools и их авторские уведомления.

Собственные материалы проекта регулируются проприетарной некоммерческой лицензией [LICENSE](LICENSE). Её условия не заменяют лицензии сторонних компонентов.

Основные зависимости:

| Компонент | Версия | Лицензия / источник |
|---|---|---|
| iText Community, commons, Bouncy Castle adapter | 9.4.0 | AGPLv3; https://itextpdf.com/how-buy/AGPLv3-license |
| Bouncy Castle Cryptography | Версия из NuGet-дерева iText | MIT; уведомления соответствующего пакета |
| ClosedXML | 0.104.2 | MIT |
| Newtonsoft.Json | 13.0.4 | MIT |
| Microsoft.Extensions.* | 8.0.0 / 10.0.0 по линии AutoCAD | MIT |
| Open XML SDK, ClosedXML.Parser, ExcelNumberFormat, RBush, SixLabors.Fonts и другие транзитивные пакеты | Зафиксированы в разрешённом NuGet-дереве сборки | Уведомления соответствующих пакетов |
| Autodesk AutoCAD .NET API | 2025/2026/2027 | Отдельные условия Autodesk; используется только для компиляции/работы в лицензированном AutoCAD, host DLL не распространяются |

Закрытая поставка с iText требует отдельной коммерческой лицензии iText либо замены этой зависимости; условия [iText](https://itextpdf.com/how-buy/AGPLv3-license) не допускают проприетарную поставку по одной лишь лицензии собственного кода.

Скрипт `scripts/Collect-Notices.ps1` извлекает из NuGet-пакетов сведения об авторах, версии, лицензии, URL и имеющиеся тексты лицензий/уведомлений. Собранные материалы включаются в bundle в `ThirdPartyNotices`; они сохраняют исходные авторские уведомления. Источники проекта и инструкции сборки поставляются отдельно через публичный репозиторий и source-архив GitHub.

Inno Setup используется как средство сборки. Его лицензия и уведомления находятся в составе официального компилятора; с плагином отдельный компилятор не распространяется. Использование компилятора в коммерческих целях регулируется условиями Inno Setup.
