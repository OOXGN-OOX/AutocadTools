## Векторные знаки

| Знак | Светлая тема | Тёмная тема |
| --- | --- | --- |
| OOXGN | [SVG](assets/ooxgn-wordmark-light.svg) | [SVG](assets/ooxgn-wordmark-dark.svg) |
| Монограмма OOX | [SVG](assets/ooxgn-monogram-light.svg) | [SVG](assets/ooxgn-monogram-dark.svg) |

Знаки построены из векторных контуров, имеют прозрачный фон и сохраняют пропорции при масштабировании. Используйте светлый вариант на светлом фоне, тёмный — на тёмном. В README вариант выбирается по теме GitHub.

## Цвета

| Цвет | HEX |
| --- | --- |
| Чёрный | `#000000` |
| Графит | `#2B2B2B` |
| Тёплый белый | `#FAF9F7` |
| Светлый серый | `#D9D9D9` |
| Нейтральный серый | `#9CA3AF` |
| Серый акцент | `#6B7280` |

Размещайте логотип на спокойном однотонном фоне. Сохраняйте пропорции, расстояния между буквами и форму X; используйте цельную заливку без обводок, теней и декоративных эффектов.

Файлы знаков относятся к собственным материалам OOXGN и регулируются [LICENSE](../LICENSE).
