# Инструменты Autocad Tools

[← Главная страница](../README.md)

## Инструменты и команды

| Инструмент | Команда | Возможности |
|---|---|---|
| Аксонометрия | `Align_Den` | Преобразование выбранной геометрии с настройкой параметров |
| Автонумерация | `AUTONUM`, `НУМ` | Текст, атрибуты, мультивыноски; префикс/суффикс, шаг, разрядность, сортировка |
| Выбор по образцу | `WSELECT` | Выбор объектов по общим и специфическим свойствам; доступ через контекстное меню |
| Сумма длин | `SUMLENGTH` | Длины, площади замкнутых объектов, группировка и единицы измерения |
| Мультикопирование | `MULTICOPY` | Шаг или число сегментов; прямая либо линия/полилиния/сплайн; предварительный показ |
| Подготовка планов | `PLANPREP` | Разбиение блоков/штриховок, удаление точек/масок/SOLID, соединение линий, серый цвет, создание блока |
| Очистка чертежа | `CLEANDWG` | Геометрия, группы, фильтры, словари, RegApps, масштабы, настройки печати, PURGE/AUDIT |
| Очистка невыбранных | `CLEANUNSELECTED` | Удаление обрабатываемых объектов, кроме выбранных |
| Сброс текста | `STRIPTEXT` | Удаление переопределений MText и свойств текста/выносок/размеров/таблиц/атрибутов |
| Вставка форматки | `AUTOCADTOOLS_INSERTFORMAT` | Вставка динамического блока WM_FORMAT из встроенного DWG на слой WM_FORMAT |
| Штамп | `AUTOCADTOOLS_STAMP` | Редактирование полей; объединённые длинные поля до 128 символов с сохранением в две части |
| Пакетная печать | `AUTOCADTOOLS_BATCHPLOT`, `WPLOT` | Форматки, размеры A0–A4 и кратные, атрибуты, порядок листов, протяжка номеров, PDF |
| Подготовка всех блоков к печати | `AUTOCADTOOLS_BLOCKS_STAGE1` | PageSetup и DSD для всех блоков ModelSpace; A4 с вписыванием |
| Подготовка для заказчика | `AUTOCADTOOLS_CUSTOMERORDER` | Новый DWG, разбиение объектов, очистка, ограничение команд копирования в текущем сеансе |
| Таблица Excel | `AUTOCADTOOLS_TABLEEXCEL` | TABLE → XLSX → редактирование → автоматический обратный импорт после закрытия файла |
| Информация | `AUTOCADTOOLS_INFO` | Сведения, версия и настройки проверки обновлений |
| Проверка обновлений | `AUTOCADTOOLS_CHECKUPDATES` | Ручная проверка новых версий GitHub |

В сумме зарегистрированы **19 имён команд**, включая псевдонимы `НУМ` и `WPLOT`.

## Мультикопирование

Выберите объекты и вызовите `MULTICOPY`. В режиме «Разметить» укажите шаг с клавиатуры или двумя точками. Через «Поделить» переключитесь на число сегментов; через «Разметить» можно вернуться обратно. Последние значения и режим запоминаются в текущем сеансе.

Затем укажите базовую и вторую точки. Например, длина 90 и три сегмента дают копии на расстояниях 30, 60 и 90. Фиксированный шаг 30 при длине 100 даст те же три копии.

Вместо базовой точки выберите «Примитив» и отрезок, полилинию или сплайн. Повторяется относительная форма траектории без переноса исходного набора на выбранный примитив и без поворота копий. Для открытой кривой направление определяется ближайшим к месту выбора концом. Для замкнутой начало определяется местом выбора; совпадающая начальная/конечная точка не дублируется.

Сохраняются атрибуты блоков, отдельные группы копий и свойства объектов. Объекты заблокированных слоёв отклоняются. До указания второй точки показываются будущие копии; при числе свыше 100 показ отключается. Предел одного запуска — 10000 копий. Esc до подтверждения не создаёт объекты. Один запуск отменяется стандартным Undo.

Поведение режимов основано на [описании ModPlus](https://modplus.org/ru/autocadplugins/mpmulticopy).

## Вставка форматки

На вкладке **Autocad Tools**, в панели «Выпуск», нажмите **Вставить форматку** или введите `AUTOCADTOOLS_INSERTFORMAT`, затем укажите точку вставки. Используется динамический блок `WM_FORMAT` из поставляемого `Assets/WM_FORMAT.dwg` с атрибутами. Форматка размещается в текущем пространстве на слое `WM_FORMAT`, поэтому её находит пакетная печать в ModelSpace. Размер и другие динамические параметры меняются стандартными свойствами блока AutoCAD.

Файл включён в установщик; исходный путь на компьютере автора не нужен. Если в DWG уже есть определение `WM_FORMAT`, используется оно — прежние вставки не переопределяются. При заблокированном слое команда сообщает об этом. Отмена выбора точки не вставляет объект.

## Сумма длин в строке состояния

Выделите линии, полилинии, дуги или сплайны: перед переключателем «МОДЕЛЬ» в нижней строке состояния появляется **Сумм. длина: 123,45**. Это длина в единицах DWG без пересчёта масштаба. Снимите выделение — индикатор скроется. Сумма пересчитывается при изменении выделения, завершении редактирования и переходе в другой документ. Кнопка `SUMLENGTH` с подробным окном сохраняется.

Если среда AutoCAD не предоставляет нативную панель, применяется механизм `MODEMACRO`, как в исходном LISP. Не запускайте одновременно старый LISP-реактор суммы длин, чтобы два инструмента не конкурировали за `MODEMACRO`.

## Проверка обновлений

Плагин проверяет [GitHub Releases](https://github.com/OOXGN-OOX/AutocadTools/releases) при запуске и каждые 24 часа работы AutoCAD. Ручная проверка доступна через кнопку «Проверить обновления» и команду `AUTOCADTOOLS_CHECKUPDATES`.

При включённом автообновлении установщик скачивается в фоне и проверяется по SHA256. Установка начинается после закрытия всех процессов AutoCAD и Core Console. Область установки сохраняется: текущий пользователь или все пользователи. Общая установка требует подтверждения прав Windows. После установки новая версия загружается при следующем запуске AutoCAD.

В окне «Инфо» можно отключить автопроверку или установку после закрытия AutoCAD и включить предварительные выпуски. Отключение автоматической установки отменяет ожидающее обновление. При отключённой автоустановке плагин предлагает скачать и установить найденный выпуск. По умолчанию предварительные выпуски исключены.

Автоматическая установка поддерживается для стандартного bundle в `ApplicationPlugins`. Для DLL, загруженной из каталога разработки через `NETLOAD`, и выпусков без установщика доступна страница загрузки. Ошибки сети и проверки файла не приводят к установке; ручную проверку можно повторить. Рабочие чертежи не закрываются автоматически.

## Примеры

### Нумерация

Выберите текст или блоки, вызовите `AUTONUM`, задайте начальный номер, шаг и префикс, затем выберите порядок. Для атрибутов укажите нужный тег. Настройки сохраняются между сеансами.

### Выпуск PDF

Сохраните DWG и вызовите `WPLOT`. Настройте имя/слой форматок, выберите листы и порядок. По умолчанию используются имя блока и слой `WM_FORMAT`; лист и наименование читаются из атрибутов `ЛИСТ` и `НАИМЕНОВАНИЕ`.

- **Сшивка:** рядом с DWG создаётся `<имя DWG>_Binder.pdf`.
- **По листам:** отдельные PDF создаются в папке `<имя DWG>_Sheets`.

Перед публикацией плагин спрашивает о сохранении DWG. Сохранение нужно для доступности подготовленных настроек фоновой печати. Для печати требуется драйвер `DWG To PDF.pc3`. После публикации PDF обрезается по размерам листов. Гиперссылки добавляются только при явно переданном адресе в API обработки PDF. Книжная ориентация учитывается; повторяющиеся номера листов не приводят к перезаписи соседних файлов.

При ошибке обработки промежуточный PDF сохраняется в `%LOCALAPPDATA%\AutocadTools\Publish`; путь выводится в командную строку. Итоговые имена файлов при повторном выпуске заменяются, поэтому сохраните нужные предыдущие результаты отдельно. Режим «По листам» не удаляет старые PDF от ранее выпущенных, но теперь исключённых листов.

### Редактирование TABLE в Excel

Вызовите `AUTOCADTOOLS_TABLEEXCEL`, выберите TABLE. Плагин создаст XLSX и откроет его в назначенном приложении. Отредактируйте и сохраните файл, затем закройте его: обратный импорт выполняется при освобождении файла. Поддерживаются объединённые ячейки; редактор XLSX должен быть установлен отдельно.

## Фактические ограничения

- Перед операциями очистки, разбиения и подготовки для заказчика используйте копию DWG: эти инструменты изменяют объекты.
- «Ограничение копирования» перехватывает команды открытого документа при загруженном плагине. Это не постоянная защита DWG от копирования в другом сеансе или программе.
- `AUTOCADTOOLS_BLOCKS_STAGE1` подготавливает PageSetup и DSD для A4 с вписыванием. Публикация выполняется средствами AutoCAD.
- Полный цикл штатной/фоновой публикации и взаимодействие с Excel требуют проверки на рабочих конфигурациях; автоматические тесты PDF не заменяют проверку PDF-драйвера AutoCAD.
- Пользовательские настройки и промежуточные файлы находятся вне установленного bundle; временные файлы публикации пока не очищаются автоматически.
- EXE не подписан сертификатом издателя; Windows может показать издателя как неизвестного.
