# Проверка проекта

[← Главная страница](../README.md)

## Запуск

Проверка структуры исходников и синтаксиса сценариев:

```powershell
.\dev.cmd Check
```

Все тесты, не требующие установленного AutoCAD:

```powershell
.\dev.cmd Test
```

Проверки команд в AutoCAD Core Console:

```powershell
.\dev.cmd Test -Suite All -AutoCAD -AutoCADVersion 2026
```

Параметры среды и доступные наборы тестов описаны в [руководстве разработчика](DEVELOPMENT.md#цикл-разработки). Результаты проверок CI доступны в [GitHub Actions](https://github.com/OOXGN-OOX/AutocadTools/actions/workflows/build.yml).

## Покрытие

| Область | Проверки |
| --- | --- |
| Структура | Регистрация команд, XML/XAML, ресурсы ленты, привязки штампа и исключение локальных рабочих файлов |
| PDF | Обрезка, ориентация, гиперссылки, сшивка, отдельные листы и сохранность исходника при ошибке |
| Настройки и обновления | Настройки, выбор версий, расписание, SHA256, ошибки загрузки, область установки, ожидание закрытия AutoCAD и отмена на .NET 8 и 10 |
| Аксонометрия | Точки привязки и направления TEXT/MTEXT, сохранение свойств текста и преобразование смещённых атрибутов |
| Мультикопирование | Шаг и сегменты, прямые и криволинейные траектории, группы, атрибуты блоков и выполнение команды |
| Упаковка и выпуск | Изменение исходников и версии, целостность артефактов, повторное использование выпуска, пропуск опубликованных версий и продолжение черновика |

Состав и критерии выполнения проверок команд:

- [Аксонометрия](../tests/AlignSkewChecks/README.md).
- [Мультикопирование](../tests/MultiCopyChecks/README.md).

Модуль `tests/AutoCADSmoke` предназначен для проверки загрузки плагина, регистрации команд, геометрии, штампа и вставки форматки.

## Проверки в полном AutoCAD

Интерактивное превью, окна, взаимодействие с Excel, PDF-драйвер и фоновая печать проверяются в полном приложении. Core Console и изолированные тесты покрывают вычисления и работу с объектами чертежа; проверка пользовательского интерфейса требует отдельного запуска AutoCAD.
