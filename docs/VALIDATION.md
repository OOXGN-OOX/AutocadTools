## Автоматические проверки

Актуальные результаты доступны в [GitHub Actions](https://github.com/OOXGN-OOX/AutocadTools/actions/workflows/build.yml).

| Проверка | Что проверяется |
| --- | --- |
| Структура | Команды, XML/XAML, значки ленты и привязки штампа |
| Сборка | Debug выбранного профиля по запросу; две линии Release DLL только при завершении версии |
| PDF | Обрезка, ориентация, явные гиперссылки, сшивка, отдельные листы и сохранность исходника при ошибке |
| Настройки | Чтение, запись, значения по умолчанию и обработка ошибок |
| Обновления | Версии, адреса релизов, расписание, ошибки сети и обработчик Idle |
| Аксонометрия | В Core Console: точки привязки TEXT/MTEXT относительно преобразованной геометрии, направления, свойства текста и смещённый атрибут блока |
| Мультикопирование | 16 расчётных проверок; Core Console: прямые/кривые, сегменты, группы, атрибуты и реальный запуск команды |
| Повторная упаковка | Изменение исходников/версии и повреждение артефактов отменяют кеш |

Команды запуска приведены в [руководстве разработчика](DEVELOPMENT.md#проверки).

14.10.2026 прошёл `dev.cmd Test -Suite All -AutoCAD`: расчёт мультикопирования, PDF, настройки и обновления на .NET 8/10, проверки кеша, аксонометрия и мультикопирование в AutoCAD 2026 Core Console. Журнал мультикопирования — `artifacts/validation/multicopy-2026.log`. Интерактивный показ курсором в полном AutoCAD и публикация GitHub workflow после отправки тега пока не проверены. Установщик текущего цикла не собирался.

## Проверки в AutoCAD

Модуль `tests/AutoCADSmoke` предназначен для проверки загрузки, регистрации команд, геометрии, штампа и вставки форматки в AutoCAD Core Console.

Отдельная проверка аксонометрии: `tests/AlignSkewChecks/Run.ps1 -AutoCADVersion 2026`. 14.10.2026 в AutoCAD 2026 Core Console прошли 144 случая TEXT/MTEXT, выбор только текста и смещённый атрибут блока. Журнал: `artifacts/validation/align-skew-2026.log`; состав проверки — в [tests/AlignSkewChecks/README.md](../tests/AlignSkewChecks/README.md). Исходный DWG с пользовательских скриншотов в этой проверке не использовался.

Проверка окон, взаимодействия с Excel, PDF-драйвера и штатной фоновой печати в полном AutoCAD ещё не завершена. Автоматические тесты не заменяют проверку этих сценариев на рабочем месте.
