# Проверки Autocad Tools

[← Главная страница](../README.md)

## Автоматические проверки

Актуальные результаты доступны в [GitHub Actions](https://github.com/OOXGN-OOX/AutocadTools/actions/workflows/build.yml).

| Проверка | Что проверяется |
| --- | --- |
| Структура | Команды, XML/XAML, значки ленты и привязки штампа |
| Сборка | Release для AutoCAD 2025, 2026 и 2027 |
| PDF | Обрезка, ориентация, явные гиперссылки, сшивка, отдельные листы и сохранность исходника при ошибке |
| Настройки | Чтение, запись, значения по умолчанию и обработка ошибок |
| Обновления | Версии, адреса релизов, расписание, ошибки сети и обработчик Idle |

Команды запуска приведены в [руководстве разработчика](DEVELOPMENT.md#проверки).

## Проверки в AutoCAD

Модуль `tests/AutoCADSmoke` предназначен для проверки загрузки, регистрации команд, геометрии, штампа и вставки форматки в AutoCAD Core Console.

Проверка окон, взаимодействия с Excel, PDF-драйвера и штатной фоновой печати в полном AutoCAD ещё не завершена. Автоматические тесты не заменяют проверку этих сценариев на рабочем месте.
