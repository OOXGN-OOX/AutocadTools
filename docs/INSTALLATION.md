# Установка Autocad Tools

[← Главная страница](../README.md)

## Установка

1. Скачайте установщик опубликованной версии из [GitHub Releases](https://github.com/OOXGN-OOX/AutocadTools/releases) или соберите его по [инструкции](DEVELOPMENT.md#bundle-и-установщик).
2. Закройте AutoCAD и Core Console.
3. Запустите установщик. Для установки всем пользователям потребуются права администратора; установка только для себя не требует повышения прав.
4. Запустите AutoCAD. В ленте появится вкладка **Autocad Tools**.

В мастере выберите установку для всех пользователей (с правами администратора) или только для себя. Путь определяется автоматически. Для текущего пользователя используется `%APPDATA%\Autodesk\ApplicationPlugins\AutocadTools.bundle`.

Стандартная папка общей установки:

```text
C:\Program Files\Autodesk\ApplicationPlugins\AutocadTools.bundle
```

Установщик выбирает DLL через манифест bundle: линия .NET 8 для AutoCAD 2025–2026, линия .NET 10 для 2027. Он не устанавливает AutoCAD и не отключает `SECURELOAD`. При необходимости проверьте `APPAUTOLOAD`, доверенный путь и сообщения AutoCAD.

Для ручной установки распакуйте ZIP с bundle и скопируйте `AutocadTools.bundle` в стандартную папку `ApplicationPlugins`. Сохраняйте рядом с DLL подкаталоги `ExcelRuntime` и `Assets`, включая библиотеку дополнительных функций. Для отдельной проверки через `NETLOAD` выбирайте DLL именно вашей линии:

```text
Contents\Windows\2025-2026\AutocadTools.dll
Contents\Windows\2027\AutocadTools.dll
```

Не загружайте обе DLL одновременно. Установка создаёт отдельный bundle и настройки в `%LOCALAPPDATA%\AutocadTools`.

### Обновление и удаление

Автообновление скачивает и проверяет установщик, затем запускает его после закрытия AutoCAD и Core Console. Настройки доступны в окне «Инфо». Для ручного обновления закройте AutoCAD и запустите новый установщик. Обновление заменяет файлы в существующем каталоге установки. При другой папке или режиме установки мастер укажет найденную копию; удалите её через Windows. Удалить плагин можно через «Установленные приложения» Windows или `unins000.exe` в папке bundle. Настройки в `%LOCALAPPDATA%\AutocadTools` и `HKCU\Software\OOXGN\AutocadTools\AutoNum` сохраняются при удалении.
