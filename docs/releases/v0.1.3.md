# Autocad Tools 0.1.3

- Копирование с нумерацией: выбранное число в тексте, атрибуте или мультивыноске; копии по точкам, вдоль кривой и в вершинах полилинии, предварительный просмотр и дробный шаг.
- Нумерация одинаковой ячейки в нескольких TABLE с сохранением остальных полей, формул, оформления и объединений.
- Пакетная печать A0–A5, кратных и произвольных рамок: точные размеры страниц, распознавание динамических форм, четыре направления сортировки, выбор папки, ведомость и сохранение существующих PDF с индексом.
- Отдельные команды импорта и экспорта XLSX; изолированная загрузка библиотек Excel и исправления обратного импорта таблиц.
- Перенос свойств штампа в несколько открытых DWG и документов Word, включая режим пустых значений. Исправлено вычисление живых полей форматки.
- Калькулятор в окне суммы длин; сохраняемые параметры инструментов; базовая точка блока при подготовке плана и серый цвет ACI 252.
- Встроенная библиотека из 174 функций LISP с зависимостями, классическое меню и панель инструментов.

Команда `ATPLOTSETUP` для предварительной подготовки A4 удалена; используйте `ATPLOT`, который готовит параметры выбранных рамок при печати.

Для установки закройте AutoCAD и запустите EXE либо замените весь bundle. Папки `ExcelRuntime` и `Assets/AdditionalFunctions` обязательны: перенос одной DLL недостаточен. Настройки пользователя сохраняются.
