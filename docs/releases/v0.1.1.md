# Autocad Tools 0.1.1

- Исправлено смещение копий при работе в перенесённой и повёрнутой ПСК, в том числе с ненулевой отметкой Z. Для длинных массивов предварительный показ охватывает всю траекторию.
- Исправлены цвет, высота шрифта и переносы текста в редакторе штампа. Размеры текста согласованы с атрибутами форматки; значения переносятся внутри ячеек, а переполнение по высоте проверяется перед применением.
- Добавлены синие подписи: загрузка PNG, рисование, локальная библиотека и назначение ячейкам штампа. Подписи сохраняются в DWG как встроенная геометрия блока `WM_FORMAT`.
- Введены единые английские и русские имена команд с префиксами `AT` и `АТ`. Добавлено окно `ATALIASES` / `АТСОКРАЩЕНИЯ` с поиском и настройкой коротких сокращений, проверкой конфликтов PGP и резервным копированием.
- Автонумерация запускается с запросом начального номера; дополнительные параметры доступны через опцию «Настройки». Расширена поддержка предварительно выбранных объектов в инструментах обработки чертежа.
- Уточнены названия режимов мультикопирования: «Шаг», «Количество» и «Кривая».

Имена команд предыдущей версии удалены. Обновите пользовательские макросы и сокращения по [таблице команд](https://github.com/OOXGN-OOX/AutocadTools/blob/v0.1.1/docs/USAGE.md#инструменты-и-команды).
