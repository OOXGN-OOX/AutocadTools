# 0.1.0 (в разработке)

- Исправлены точки привязки TEXT/MTEXT и смещённых атрибутов при преобразовании в аксонометрию.
- MULTICOPY: шаг или число сегментов, переключение режимов, выбор линии/полилинии/сплайна как относительной траектории, сохранение атрибутов блоков и отдельных групп копий.
- Исправлена обработка предварительного показа: объекты создаются один раз, временные ресурсы освобождаются, для более 100 копий показ отключается.
- Разделены локальные проверки, пробная Debug DLL и завершение версии. Пакетирование и публикация перенесены на конец цикла.
- Добавлен автоматический выпуск подготовленной версии из main с проверкой уже опубликованных версий.
- Добавлено фоновое скачивание обновлений с проверкой SHA256 и установкой после закрытия AutoCAD.
