# Autocad Tools 0.1.0

- Обновлён интерфейс инструментов: единая тёмная тема, плоские элементы управления, читаемые формы и векторные значки ленты для обеих тем AutoCAD.
- В редакторе штампа сохранено расположение полей основной надписи, улучшены контраст и выделение редактируемой ячейки. Настройки нумерации сгруппированы по формату номера и порядку обработки.
- Исправлены точки привязки TEXT/MTEXT и смещённых атрибутов при преобразовании в аксонометрию.
- Переработано мультикопирование: шаг или число сегментов, относительная траектория по линии, полилинии или сплайну, сохранение атрибутов и независимых групп копий.
- Исправлено освобождение ресурсов предварительного показа копий; для больших наборов показ ограничен.
- Добавлены фоновая проверка обновлений, проверка SHA256 скачанного установщика и установка после закрытия AutoCAD.
- Настроены автоматическая сборка и публикация завершённых версий из `main`.
