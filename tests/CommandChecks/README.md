# Проверки команд и сокращений

```powershell
dev.cmd Test -Suite Commands
```

Проверяются состав двуязычного каталога, одинаковые флаги английской и русской команд, отсутствие лишних регистраций, обработка конфликтов и повторяющихся сокращений, сохранение кодировки и посторонних записей PGP, резервное копирование и отказ при одновременном изменении файла.

Проверки используют временные PGP в отдельном каталоге и не изменяют профиль AutoCAD. UTF-8 с BOM и без него, Windows-1251 и UTF-16 проверяются отдельно. Нативный запуск английской и русской команды мультикопирования проверяется набором [MultiCopyChecks](../MultiCopyChecks/README.md).
