# Проверки мультикопирования

`dev.cmd Test -Suite MultiCopy` запускает 16 расчётных проверок без AutoCAD. Дополнительно `-AutoCAD -AutoCADVersion 2026` собирает только тестовую DLL с исходниками MULTICOPY и запускает отдельный процесс Core Console с новым несохранённым чертежом.

Проверяются шаг и сегменты, большие координаты, направление от обоих концов линии, полилиния с поворотом и дуговым участком, замкнутая траектория без дублирования начала и сплайн с шагом по длине. Проверка копирования контролирует атрибуты блока, их значения и положения, самостоятельные группы каждого набора, сохранность исходной группы и отказ при заблокированном слое.

Затем запускается настоящая команда MULTICOPY с английскими глобальными ключевыми словами в русской локализации AutoCAD: «Поделить → 3 → Примитив», «Разметить → 30 → две точки». Круг из начала координат должен получить копии с X=30, 60, 90, хотя выбранная линия расположена от X=200 до X=290.

Результат — `MULTICOPY_PASS`; журнал `artifacts/validation/multicopy-2026.log`. Загрузка тестовой DLL в рабочий AutoCAD одновременно с плагином запрещена: она регистрирует ту же команду. Отрисовка превью при движении мыши требует отдельной проверки в полном AutoCAD.
