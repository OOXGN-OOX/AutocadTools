# Проверка аксонометрии в AutoCAD

Из корня репозитория:

```powershell
.\tests\AlignSkewChecks\Run.ps1 -AutoCADVersion 2026
```

Нужен установленный AutoCAD 2026 или 2027 и соответствующий SDK .NET. Скрипт использует локальную копию SDK из `artifacts/tools/dotnet`, если он доступен; другой путь можно передать через `-DotnetPath`.

Тестовая DLL компилирует непосредственно исходники команды `ATISO` / `АТАКСО`, калькулятора и обработки текста. Она загружается в отдельный процесс Core Console с новым несохранённым чертежом. Не загружайте эту DLL в рабочий AutoCAD одновременно с плагином: она содержит ту же команду.

144 случая сравнивают точки привязки и направления TEXT/MTEXT с геометрией, преобразованной через фактическое создание и расчленение временного блока. Проверяются шесть углов, три базовые точки (включая большие координаты и ненулевую отметку Z), пять способов выравнивания TEXT и три MTEXT. Проверяются сохранность высоты, ширины, наклона и форматирования, выбор только текста и вручную смещённый атрибут блока.

Ожидаемый результат — `ALIGN_SKEW_PASS`. Журнал сохраняется в `artifacts/validation/align-skew-<версия>.log`. Тестовый чертёж закрывается без сохранения. Скрипт завершится ошибкой, если проверки не выполнились, не прошли либо процесс не завершился за 60 секунд.
