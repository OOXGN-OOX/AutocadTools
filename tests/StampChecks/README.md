# Проверка штампа и подписей

```powershell
.\dev.cmd Test -Suite UI
.\dev.cmd Test -Suite Stamp -AutoCAD -AutoCADVersion 2026
```

WPF-проверка создаёт редактор подписи, рисует штрих, проверяет обрезку изображения и синий цвет; сохраняет виды при 100% и 150% масштабе, в обычном и минимальном размере. Также проверяется светлый текст штампа при чёрном стиле TextBox в приложении-хосте.

Отдельный процесс Core Console проверяет целые значения до 1000 символов и старые парные свойства, размещение подписей в двух строках `WM_FORMAT`, цвет встроенной геометрии, повторное применение без дубликатов, смену динамического формата, сохранение и повторное открытие DWG, снятие подписей. Рабочие чертежи не используются. Успех: `STAMP_PASS` без `STAMP_FAIL`.

Интерактивные проверки в AutoCAD охватывают импорт PNG, рисование мышью или пером, выбор из библиотеки, применение к форматкам и отображение после изменения формата листа.

Проверки текста включают размер 5 / 2,5 мм, сохранение связи обычного текста со свойством DWG, перенос строки без пробелов, отклонение переполнения по высоте и повторное размещение после смены динамического формата. WPF-проверка контролирует соотношение размеров шрифтов и перенос текста в редакторе.
