# Проверка интерфейса

```powershell
.\dev.cmd Test -Suite UI
```

Требуются Windows и runtime .NET Desktop 8 x64. Набор загружает исходные XAML и общие ресурсы WPF, подставляет данные форм и создаёт изображения при масштабе 100% и 150%, в обычном и минимальном размерах. Проверяются размещение действий, длина подписей кнопок, раскрытие списков и наличие редактора у списков с вводом текста.

Изображения сохраняются в `artifacts/validation/ui`. Отдельно выводятся векторные значки ленты на светлом и тёмном фоне.

Проверка выполняется без AutoCAD: обработчики событий исключены из загружаемой разметки, команды чертежа не запускаются. Она дополняет проверку сборки и функциональные тесты, не заменяя проверку взаимодействия с AutoCAD и средствами доступности.

Окно команд и сокращений проверяется при 100% и 150% DPI в обычном и минимальном размере: двуязычный каталог, поиск, доступность кнопок и блокировка применения при конфликте PGP.
