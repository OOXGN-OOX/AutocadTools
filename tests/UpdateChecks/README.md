# Проверки обновлений

```powershell
.\dev.cmd Test -Suite Updates
```

Проверки запускаются на .NET 8 и 10. Тестовый HTTP-обработчик воспроизводит ответы GitHub без сетевого подключения: проверяются выбор версии и файлов выпуска, SHA256, размеры, повреждение файла, отмена загрузки и очистка частичных данных. Проверяется подготовка встроенного модуля установки и определение области установки.

`tests/UpdateRunnerChecks` проверяет ожидание закрытия AutoCAD, повторную проверку контрольной суммы, целевой каталог, отмену, тайм-аут и защиту от понижения версии. Запуск установщика заменён тестовой функцией; установленный плагин и рабочие чертежи не изменяются.

Для проверки установки и обновления EXE используется `scripts/Test-Installer.ps1` с тестовым установщиком и изолированным каталогом. Общая установка и запрос прав Windows требуют отдельной проверки в соответствующей среде.
